## 0. Pre-registration (written at T+3h36, before any S6 result was looked at)
**Hypothesis.** 3Di helps at deep/remote levels: fewer S0 fissions (remote homologs) and better deep-node
decisions; little effect at shallow nodes.

**Data.** `data/structure/orthobench_3di_best.fa`: exact-sequence AFDB-v6 3Di, 202,475 / 251,378 OrthoBench
proteins (80.5 %). DEV RefOG genes: 948, of which 66.7 % have 3Di (lower than overall: chicken, dog, zebrafish,
rat and non-canonical isoforms are the gaps). Proteins without 3Di fall back to sequence everywhere.

**Negative control.** Shuffled 3Di, seeds 11/23/47 (`structure.shuffled_3di`): proteins sorted by length, cut into
bins of 20, 3Di strings permuted within each bin as a derangement (no protein keeps its own string), donor string
resampled to the recipient length (nearest index). The AA sequence is unchanged, so the shuffled arm keeps
Foldseek's AA-substitution component and isolates the 3Di information. Per-residue identity of shuffled to real
3Di: 0.161 (composition background), vs 1.0.

**Exp 1 — S0 rescue.** Units: the selected S0 partition (`work/S0/2sA_dc30_cc_sh30_RA/families.tsv`).
One structure representative per S0 stage-1 cluster (DIAMOND rep if it has 3Di, else longest member with 3Di;
38,802 of 42,732 clusters), searched all-vs-all with `foldseek search --alignment-type 2` (3Di+AA, -s 9.5,
e ≤ 1e-2 stored, max-seqs 1000). Families joined by union-find over hits in increasing e-value.
Grid: e ≤ {1e-3, 1e-5} × small_max {10 (one side ≤ 10 genes), any}; aligned span ≥ 0.3 of the shorter protein
(S0's rule); joins that would exceed 7,500 genes skipped (S0 gmax). Metrics on DEV RefOGs only:
completeness, mean fission, best frac, fusion proxies (fusion rate, foreign-RefOG fraction), Σg²/N², max family.
Selection: max DEV completeness, ties → lower Σg². Keep: completeness(real) − mean(shuffled) > 0 and
completeness(real) − off > seed spread (max − min over the 3 shuffles).

**Exp 2 — structure-aware scores for deep/ambiguous decisions.** Pair set: every in-family pair of the
sequence ScoreTable (`work/core_v0_ob/run_v2`, hybrid DIAMOND+MMseqs2) in the families holding DEV RefOG genes
(evaluation scope; other families cannot change DEV metrics since the merge is family-local), both genes with
3Di, plus self pairs, aligned with `foldseek structurealign --alignment-type 2` on an explicit `tsv2db` pair list.
Score: S_3di = bits/max(self_a, self_b) (same normalisation as the merge's norm_max). Calibration to the
sequence scale: least-squares line d_seq ≈ a + b·d_3di (d = −ln S) on pairs with both; combined
`avg`: S = sqrt(S_seq·S_3di'), `max`: max(S_seq, S_3di'). Written into a ScoreTable (bits' = S·max(self_seq)),
so the unchanged merge (default config = hybrid local-tree mode; its NJ distance is −ln S) consumes it — **no core
change needed**. Arms: scope deep (pairs whose species LCA is Euteleostomi, Chordata, Ecdysozoa or Bilateria: the
tree-mode nodes and the root) or all; mode avg or max; × real / shuf11 / shuf23 / shuf47; off = sequence only.
Metrics: DEV OG-level F (scripts/orthobench_dev_eval.py) and pair P/R/F1 (scripts/orthobench_dev_pairs_eval.py),
pair F1 split deep (vert–teleost, vert–invert, invert–invert) vs shallow (mammal, tetrapod, teleost–teleost).
Primary endpoint: DEV pair F1 (OG-F on 34 RefOGs is too noisy, S5). Keep rule as above with pair F1;
paired bootstrap CI over RefOGs reported.

**Exp 3 — uncovered proteins.** Pair metrics of each Exp-2 run split by how many of the two genes have 3Di
(2 / 1 / 0); effect = Δ vs off per subset.

**Addendum (T+4h50, after the Exp-1 and Exp-2 `seq` results, before any `miss` result).** Pair set `miss`:
in-family pairs of the same DEV-holding families (≤ 5,000 genes) that the sequence ScoreTable left unscored
(DIAMOND miss without MMseqs2 re-alignment in families > 1,000 genes, or no alignment at e ≤ 10), both genes with
3Di: 14.7 M pairs. They enter the merge only if Foldseek e ≤ 1e-3 (the Exp-1 link threshold;
`combine_scores(miss_evalue=1e-3)`), with S = calibrated S_3di. Arms `deep:avg:seq+miss`, `deep:max:seq+miss`,
same controls and keep rule. Exp-1 post-hoc arms (singletons-only, bidirectional coverage, and the `attach` rule)
were added after seeing the real-3Di grid and are labelled post hoc in every table.


## 1. Implementation notes
- **Foldseek DB without structures** (documented route, no C-alpha needed for `--alignment-type 2`):
  `foldseek base:createdb aa.fasta db --shuffle 0` and `foldseek base:createdb 3di.fasta db_sstmp --shuffle 0`, then
  rename `db_sstmp{,.index,.dbtype}` → `db_ss*`. Keys agree because both inputs have the same order. Checked: search
  and `structurealign` work and give identical bits for the same pair (test `test_build_db_and_align_pairs`).
- **Explicit pair alignment**: `foldseek base:tsv2db pairs.tsv pref --output-dbtype 7` +
  `foldseek structurealign db db pref aln --alignment-type 2 -e inf --tmscore-threshold 0 --lddt-threshold 0 -a`
  (the core's MMseqs2 trick; self pairs give self-scores).
- 3Di: 202,475 / 251,378 proteins (80.5 %), 0 length mismatches with the proteome sequences. DEV RefOG genes:
  66.7 % covered; dev truth pairs: both 3Di 9,735, one 5,948, none 3,463.
- **No core change was needed**: the merge reads only `bits`/`self_bits` (norm_max), so the structure-aware score is
  written as a ScoreTable with bits' = S·max(self_a, self_b); `combine_scores(..., node_mask=...)` restricts it to pairs
  whose species LCA is a deep node, i.e. structure enters only at those nodes (each leaf pair enters the merge once,
  at its LCA). Families are implicit in the edges, so the S0 rescue downstream is also a ScoreTable
  (`scripts/S6_s0_downstream.py`, new pairs aligned with the core's `scoring._mmseqs_align_pairs`).
- Calibration: d_seq ≈ 0.733 + 0.881·d_3di, least squares on the 1.89 M pairs with both scores (real 3Di); shuffled 3Di: 0.03 + 0.44·d_3di (the 3Di
  part of the score is noise there).

### 3.4 Why structure does not help the merge (diagnostics)
**Ortholog-vs-paralog ranking** (`scripts/S6_discrimination.py`, `discrimination.json`): triplets (a, ortholog o,
paralog p in the same species) from the DEV RefOG tree labels, all scores available; accuracy of S(a,o) > S(a,p):

| triplets | n | seq | 3Di+AA real | shuffled 11/23/47 | avg (seq, 3Di) | max (seq, 3Di) |
|---|---|---|---|---|---|---|
| deep classes | 3,004 | **0.751** | 0.694 | 0.624 / 0.639 / 0.590 | 0.734 | 0.752 |
| shallow classes | 5,152 | **0.945** | 0.933 | 0.838 / 0.844 / 0.820 | 0.942 | 0.945 |

3Di+AA − seq: deep −0.057 [−0.088, +0.012], shallow −0.012 [−0.020, −0.007]; real − shuffled: deep +0.076
[−0.003, +0.180], shallow +0.099 [+0.078, +0.118]. 3Di carries homology signal but separates orthologs from
paralogs worse than sequence: paralogs inside an orthogroup share the fold, while sequence keeps the faster
post-duplication divergence. Combining (avg) dilutes the sequence signal; max returns it.

**Coverage of truth pairs** (`pair_coverage.json`): sequence already scores 91 % of DEV deep ortholog pairs (2,445 /
2,683) and 99 % of shallow ones. Of the 238 unscored deep ortholog pairs, structure-only (e ≤ 1e-3) rescues 2; it
rescues 184 deep and 470 shallow *paralog* pairs. Shuffled: 0–1. So the remote homologs 3Di finds in-family are
almost all paralogs (superfamily members), which an orthology merge must keep apart.

## 4. Exp 3 — proteins without 3Di
Pair F1 by number of 3Di-covered genes in the truth pair (`tables.md` Exp 3). Off: both 0.7358, one 0.7239, none
0.7779. Under the real-3Di arms the uncovered subset changes by +0.027 to +0.049 and the covered one by −0.011 to
+0.013, and the shuffled runs show changes of the same size and sign pattern (none: −0.027 to +0.065). The
fallback (sequence score for any pair lacking 3Di) is mechanically safe — uncovered pairs keep their exact
sequence score — but merge decisions are coupled through units, so effects leak to uncovered pairs; there is no
differential benefit for covered pairs that survives the control.

## 6. Integration (for the core owner)
- Exp 2 needs no hook: `ancestra.structure.combine_scores` turns (sequence ScoreTable, Foldseek pair scores) into a
  ScoreTable the unchanged merge consumes. Since the layer is killed, nothing should change in `pipeline.py`.
- If the S0 rescue is ever re-tested with a merge guard, the minimal pipeline hook would be (not proposed for
  default; `families.py` / `pipeline.py` untouched): after the families stage, when `--structure-3di FASTA` is
  given, `fam = structure.link_families(fam, hits, gt.lengths, evalue=1e-3, small_max=10, mode="attach")[0]` with
  `hits` from `structure.search` of stage-1 structure reps against themselves (`scripts/S6_s0_search.py` logic), and
  the attached genes flagged so the merge can restrict them (e.g. root-only joins).

## 7. Caveats
- 34 DEV RefOGs; OG-F swings of ±5–9 points come from single RefOGs (RefOG010 in the downstream run).
- Exp 2 scores only families holding DEV RefOG genes (evaluation scope; the merge is family-local, so other families
  cannot change DEV metrics). Families > 5,000 genes: `miss` pairs not scored (cap rule).
- Shuffled 3Di + real AA is not a pure null for Foldseek e-values (2× more S0 links than real); "real − shuffled"
  for completeness is still clean (0 rescued RefOGs under shuffling).
- Post-hoc arms (attach, singletons-only, bidirectional coverage, `miss` addendum after seeing `seq` results) are
  labelled; none changes a verdict.
