S1 Table. Full Quest for Orthologs 2022 results for all methods (S1_Table.csv).
Ancestra rows: frozen method (freeze-v1), run and scored locally with the official QfO benchmark code.
Other rows: published OpenEBench QfO 2022 values. As a check of the local setup, 10 of these submissions were re-scored locally on SwissTree, TreeFam-A and VGNC and reproduced all 60 published TPR/PPV values.
"±": 95% CI half-width for SwissTree/TreeFam-A/VGNC. For GO and EC it is 1.96 x SEM (checked; the source summary mislabels it as SEM, see S3 Text). FAS and STD use the same field, which was not checked separately.
STD/G_STD2: fraction of incorrect trees, Robinson-Foulds distance (lower is better) and number of trees sampled.
Source: results/qfo_final/summary.tsv in the research repository.
